# SOP Deep Research

## Scope

Apply this SOP when work depends on current facts, unstable facts, official documentation, primary-source citation, package trust, internet-connected behavior, regulatory or standards claims, security-sensitive claims, CVEs, advisories, exploit status, supply-chain risk, or direct quotations.

## Required Skill

Use `C:\Users\downl\.codex\skills\deepresearch-defense-standard\SKILL.md` before meaningful web research in Codex.

## Procedure

1. Define objective, scope, timeframe, product or package, jurisdiction when relevant, and acceptable source quality.
2. Prefer primary sources:
   - official vendor or maintainer docs
   - standards bodies
   - official advisories
   - package registry metadata
   - official repositories and changelogs
3. Use secondary sources only to widen context or compare claims.
4. For security and package-trust work, check advisories, CVEs, maintainer or owner history, release provenance, and recent release behavior when practical.
5. Separate verified facts, inferences, unknowns, and residual risks.
6. Cite sources when web information influences the answer or implementation.

## Defensive Boundary

Security research under this SOP is defensive only. Use it for hardening, validation, incident response, patching, audit, and responsible disclosure. Do not provide exploit code, weaponization steps, stealth guidance, or misuse optimization.

## Completion Evidence

Record the sources used, dates checked when relevant, unresolved uncertainty, and any skipped primary-source checks in the implementation log.
