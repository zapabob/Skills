## Usage Rule

Apply the common standard first, then `SOP-Implementation-Start-Gate.md`, then the relevant cross-cutting SOPs, then the relevant domain SOPs, then the language SOP for the implementation language in use.

For frontend UI/UX work, apply `SOP-WebApp-Development.md` and `SOP-Frontend-Design.md` together before the language SOP.

For security-sensitive work, apply `SOP-Security.md` and the relevant Codex Security skill before implementation. For current facts, official documents, package trust, or security research, apply `SOP-DeepResearch.md` before implementation.
