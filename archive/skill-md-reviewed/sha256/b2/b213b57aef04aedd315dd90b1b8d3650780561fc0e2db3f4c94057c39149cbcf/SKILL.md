# AI × X × note 収益導線自動化システム

このスキルは、X（旧Twitter）での集客から、noteの販売、公式LINEへの誘導までの収益導線を、AIを活用して半自動化するための指示書（プロンプト群）です。
以下の手順に沿って、各フェーズのAIプロンプトを実行してください。

## フェーズ 1: 市場リサーチ＆コンセプト設計

最初のステップとして、あなたが参入する市場を定義し、コンセプトを設計します。
以下のプロンプトをAIに送信して、アカウントの方向性を決定してください。

```text
# プロンプト（ペルソナ＆コンセプト決定）
あなたは優秀なウェブマーケターです。
AIを活用した副業（例：X×note、コンテンツ販売）に興味があり、本業が忙しく1日1〜2時間しか作業できない20〜40代をターゲットにビジネスを展開します。
以下の要素を考慮し、私のアカウントの「コアコンセプト」「Xのプロフィール文（160文字以内）」「note商品タイトルの候補3案」を提案してください。

- 独自のウリ: 1日15分のコピペで完結、AIによる執筆の完全自動化
- コンセプト方針: 「労力ゼロ」ではなく「初期設定後は半自動で回る現実的なシステム」
```

## フェーズ 2: X（旧Twitter）ポスト量産

コンセプトが決まったら、日々の集客用にXのポストを量産します。

```text
# プロンプト（Xポスト1週間分の作成）
あなたは実績のある【ターゲットに向けた専門家（例：AI副業コンサルタント）】です。
【ターゲットの悩み（例：時間がなくて副業が続かないこと）】を解決するためのX（旧Twitter）のポストを、以下の条件で7日分作成してください。

- 140文字以内で、改行を効果的に使うこと。
- 読者の興味を惹くキャッチーな1行目から始めること。
- 専門用語を避け、小学5年生でもわかる言葉を使うこと。
- 各曜日のテーマ:
  - 月：共感（過去の失敗談やよくある悩み）
  - 火：ノウハウ（ちょっとしたAIの実践的な使い方）
  - 水：マインド（結果を出すための考え方）
  - 木：ノウハウ（実績や小さな成功体験の共有）
  - 金：図解やリスト（保存されやすい有益情報）
  - 土：長文（価値観の共有やストーリー）
  - 日：実績アピール＋note無料部分への誘導
```

## フェーズ 3: note記事（有料コンテンツ）の自動生成

Xから誘導したユーザーに向けた有料noteを執筆します。

```text
# プロンプト（note記事構成・本文の生成）
あなたはプロのセールスライターです。
「AI×X×noteの自動収益化ロードマップ」をテーマにした有料noteの【無料部分】と【有料部分】の初稿を作成してください。

# 構成条件
【無料部分】
1. 導入・共感：読者の今の悩みに寄り添う
2. 問題提起：手作業（気合と根性）でやっているから失敗する事実を指摘
3. 新常識の提示：AIによる半自動化システムの有用性をアピール
4. このnoteで得られるベネフィット：1日15分の作業で月5万を目指せること
5. ペイウォール直前の煽り：ここから先は具体的な仕組み構築手順と先行者利益の保護について

【有料部分】
1. 準備編：AIツール群の初期設定
2. アカウント設計：売れるペルソナ設定の方法
3. 無限生成システム：ポスト量産の具体的手法
4. 販売直後のダッシュ戦略：Xでの告知方法
※最後に、本noteのレビュー（Xの引用リポスト）をした人限定の特典（『画像生成アイキャッチマニュアル』など）を案内し、公式LINEへ誘導する文章を入れてください。
```

## フェーズ 4: リスト化とLINEステップ配信

noteの購入者や無料読者を公式LINEに誘導し、リスト化します。
以下のプロンプトでLステップ（自動配信）のシナリオを作成します。

```text
# プロンプト（LINEステップシナリオ作成）
あなたは敏腕なダイレクトレスポンスマーケターです。
noteから公式LINEに登録してくれた読者に対して、最終的に「AI✕SNS自動収益化 期間コンサルティング（バックエンド商品）」を販売するための、7日間のステップ配信メッセージを作成してください。

# 配信シナリオの流れ
- 1日目：お礼、登録特典の配布、AIを活用するマインドセット
- 2日目：自身の失敗談と解決のストーリー（共感）
- 3日目：稼げない理由は「間違った努力」であるというパラダイムシフト
- 4日目：実際に成果を出したお客様の声や実績（社会的証明）
- 5日目：本気の人だけをスクリーニングする宣言
- 6日目：バックエンド商品の募集開始案内
- 7日目：締め切りリマインドとFAQ、背中を押すメッセージ
```

## ベストプラクティス

- 生成された出力はそのまま使うのではなく、ご自身の実体験や数字データを加えて「人間味」を持たせてください。
- Xの投稿では、適宜トレンドのキーワードや画像要素（アイキャッチや図解）を組み合わせることでCTRが向上します。
- このシステムを定期的に見直し（A/Bテストなど）、AIのプロンプトをチューニングすることで収益性をさらに高めることができます。
