# career_documentation Skill

Target: Create professional career documents for non-traditional paths.

Trigger: User requests career document creation for unusual situations.

## When to Use
- User requests cover letter, resume, or職務経歴書 for non-standard career situations
- User transitions between career paths
- User is in atypical employment situation and needs documentation
- User specifies alternative education path
- User prefers concise vs. verbose output style

## Core Framework
1. Situation Assessment
2. Document Type Selection
3. Key Highlighting
4. Format Adaptation
5. KPI/Goal Alignment

## Pitfalls
- Dont assume traditional career paths are the only option
- Dont discard non-traditional experience as gaps
- Dont forget user constraints

## Examples
- 39yo welfare recipient graduate school
- Technical professional freelance
- Career pivot at 40+
