# Visual Design Critique

Use this skill when the user asks for visual critique, comparison against references, originality risk analysis, or redesign guidance based on attached images.

## Core workflow

1. Identify the user’s actual intent before judging.
   - Are they asking for emotional reassurance, originality risk, a redesign path, or a technical design breakdown?
   - If the user is discussing their own creative work, treat it as authorship-sensitive: be candid but not accusatory.

2. Load and inspect each image explicitly.
   - For multiple attachments, analyze them one by one by file path or URL.
   - Do not imply that all images were individually inspected if only one was loaded.
   - If the message contains several images, give a short inventory: “I checked A/B/C” or “I only checked the last image so far.”

3. Separate resemblance into components.
   - Silhouette/proportions
   - Front/rear lighting signatures
   - Cabin placement and glasshouse
   - Fender volume and stance
   - Side sculpting / intakes / negative space
   - Surface language: organic, faceted, aero, retro, luxury, game-like, etc.
   - Color/material/photographic presentation

4. Avoid lazy “copy/paste” language unless evidence is overwhelming.
   - Prefer: “converges on the same design grammar,” “shares a strong motif,” “uses a similar solution,” or “sits in the same reference cluster.”
   - Explain that AI latent priors plus human aesthetic selection can converge on existing designs without direct intent.

5. Translate taste into abstractions.
   - Ask/answer: what did the user likely respond to?
   - Preserve the abstract taste while replacing the specific borrowed-looking solution.
   - Example: keep “low, tense, elegant hyper-EV” while changing the exact horizontal light bar, side scoop, or rear lamp logic.

6. Give redesign levers at the skeleton level, not only cosmetic fixes.
   - Change the lighting architecture.
   - Move/reshape the cabin or beltline.
   - Alter major volumes and stance.
   - Relocate or hide intakes/negative space.
   - Change rear signature and diffuser logic.

## Tone for this user

- Use casual Japanese.
- Address the user as “とうふ” when directly addressing them.
- If the user corrects identity/name, acknowledge cleanly and do not carry over old nicknames.
- Validate the creative instinct when appropriate: if a design resembles a high-quality real work, frame it as evidence of compatible aesthetic judgment before discussing originality risk.
- Be precise, not theatrical; avoid overstating certainty from a single image.

## Pitfalls

- Do not claim to have processed every attachment when the tool only loaded one image.
- Do not conflate “similar design grammar” with plagiarism.
- Do not give only reassurance; provide concrete elements to change if the user wants to differentiate the design.
- Do not let one reference dominate the analysis if the design likely sits in a broader cluster (e.g. Battista / Rimac Nevera / Lotus Evija / McLaren-like motifs).
