# Political Scenario Modeling Skill

Model political outcomes using game theory and Monte Carlo simulation for probability estimation.

## When to Use
- Estimating passage probability of legislation (constitutional amendments, key bills)
- Analyzing coalition dynamics and party bargaining positions
- Modeling multi-stage political processes (Diet passage → national referendum)
- Quantifying "conventional wisdom" political judgments
- Stress-testing scenarios against parameter uncertainty

## Prerequisites
- Python 3.9+ with numpy
- Basic game theory literacy (Nash equilibrium, subgame perfection)
- Japanese political system knowledge (Diet rules
